# SillyWardrobe — Wardrobe & References

Personal fork based on the original SillyWardrobe project.

This version keeps the original wardrobe/gallery UI and removes the image-generation and try-on entry points.

Included:
- Original wardrobe modal and bottom-bar shirt button
- Bot / User wardrobes
- Personal/shared wardrobes
- Outfit upload, activation, editing, sorting and categories
- Original gallery
- Multiple visual references per outfit, each with an image, name, description and enabled flag

Image generation, try-on, provider selection and vision auto-description are disabled.

Install the folder containing `manifest.json` under:
`SillyTavern/data/<user>/extensions/sillywardrobe-wardrobe-references/`
