# Wardrobe Reference Manager

Wardrobe-only SillyTavern extension.

## Included
- Wardrobe button in the bottom send bar.
- Bot and user/persona wardrobes.
- Personal and shared wardrobe modes.
- Outfit categories, filters and sorting.
- Multiple outfits with one active outfit per side.
- Outfit name, description, tags and multiple visual references.
- Image upload and URL references.
- JSON import/export.
- Duplicate/delete/edit/activate controls.
- Active outfit text injection.
- Optional visual reference injection for multimodal Chat Completions.
- Gallery of images already present in the current chat and character image folder.

## Not included
Image generation APIs, generation commands, try-on generation, generation profiles and image-generation settings.

## Install
Install from the repository URL in SillyTavern when the repository is accessible, or copy this folder to `data/default-user/extensions/wardrobe-reference-manager/` and restart SillyTavern.
